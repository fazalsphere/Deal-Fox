# 🚀 Deal Flex — Build & Bidding Landing Page

**Deal Flex** is a modern, responsive landing page designed for a startup offering deal-based bidding and project collaboration services. Built using HTML, CSS, and JavaScript, this project demonstrates sleek UI design, mobile-first responsiveness, and dynamic interactivity.

---

## 🔍 Features

- ✅ Hero Section with call-to-action
- ✅ Clean and responsive layout
- ✅ Category-based filtering using JavaScript (e.g., Food Deals, Card Deals)
- ✅ Scroll-based smooth animations (optional future)
- ✅ Mobile-first approach using flexbox and media queries
- ✅ Modular and semantic code structure

---

## 🛠 Tech Stack

- HTML5
- CSS3 (custom CSS with utility classes)
- JavaScript (DOM manipulation + filtering logic)
- Git & GitHub

---

## 🧪 JavaScript Interactivity

This project includes a simple yet effective **deal filter system** using vanilla JavaScript. Users can filter deals by categories like:

- 🍔 Food Deals  
- 💳 Card Deals  
- 🎁 Other Offers  

> This showcases the ability to dynamically update the DOM and control visibility of elements using event listeners and class toggling.
